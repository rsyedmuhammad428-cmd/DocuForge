# Phase 6 - Branded installer wizard
# Running DocuForge needs nothing from this file: the installer contains everything.
# This file lists what you need to BUILD the installer. It adds no new dependencies to Phase 5.

# ---- Install once on the build machine (Windows 10/11 x64, or GitHub Actions "windows-latest") ----
#   Node.js >= 22 and npm
#   Python 3.12 or newer (tick "Add python.exe to PATH")
#   Git

# ---- Commands, run in the DocuForge folder ----
#   npm ci                    installs the app packages from package-lock.json (Electron, electron-builder, ...)
#   npm run engine:setup      creates python-engine\.venv and installs the packages below
#   npm run dist              builds everything and writes release\DocuForge-Setup-<version>.exe
#                             (installs pyinstaller and pip-licenses itself; electron-builder downloads the
#                              NSIS tools the first time, so the first build needs internet)
